# Security Policy

## Supported Versions

Currently, we only support the latest version of CyberRakshak. We recommend always using the latest version to ensure you have the latest security patches.

## Reporting a Vulnerability

If you discover a security vulnerability in CyberRakshak, please follow these steps:

1. **Do not** create a public issue on GitHub
2. Email the maintainers directly at security@cyberrakshak.example.com
3. Include the following information in your report:
   - Description of the vulnerability
   - Steps to reproduce the vulnerability
   - Potential impact of the vulnerability
   - Any possible mitigations you've identified

## Response Time

We strive to respond to security vulnerability reports within 48 hours. Our response will include:

- An acknowledgment of your report
- An estimated timeline for a fix
- Whether a CVE will be requested

## Security Updates

Security updates will be released as soon as possible after a vulnerability is confirmed and a fix is developed. Critical vulnerabilities will be prioritized and may result in an immediate patch release.

## Best Practices

To ensure the security of your CyberRakshak installation:

- Always use the latest version
- Use strong, unique passwords for all accounts
- Regularly update your dependencies
- Restrict access to the application to authorized users only
- Monitor logs for suspicious activity
- Use HTTPS in production environments

## Security Considerations

When deploying CyberRakshak in production, consider the following:

- Change default passwords and credentials
- Configure proper firewall rules
- Use a reverse proxy with SSL termination
- Regularly backup your database
- Monitor for unauthorized access attempts
